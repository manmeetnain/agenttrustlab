DEVELOPER WORKFLOW

Make trust a release gate

The same declared verification runs locally and in continuous integration.

01

Run the suite

agenttrust run examples/basic_suite.py \
  --store agenttrustlab.db

Produces JSON, portable HTML and an immutable local report.

02

Gate with pytest

pytest -m agenttrust \
  --agenttrust-baseline main

Fail pull requests on policy violations or trust regressions.

03

Verify evidence

agenttrust verify \
  agenttrust-manifest.json \
  agenttrust-report.json

Validate canonical digests and optional Ed25519 signatures.
