# Trust model

AgentTrustLab does not certify universal safety. It produces independently reproducible, standards-mapped evidence showing whether an agent satisfies a declared release policy.

## Three distinct layers

1. **External frameworks define coverage.** Controls map to OWASP Agentic Top 10, MITRE ATLAS, NIST AI RMF, ISO/IEC 23894 and ISO/IEC 42001 where applicable. A mapping is not a claim of certification.
2. **Measurements record observable facts.** Reports contain test, corpus, policy, adapter, model, seed and environment versions alongside traces, state changes and limitations.
3. **Release profiles define thresholds.** Organizations select or customize an explicit policy appropriate to their impact and risk appetite.

Critical security failures are hard gates and cannot be averaged away by a composite score. “Not tested,” “not applicable,” and “passed” remain distinct states.
